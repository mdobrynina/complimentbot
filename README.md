# Telegram Mood Bot
----------------

## Описание  
Telegram Mood Bot — это Telegram-бот на Java, который анализирует настроение пользователя по сообщениям и ведёт персональный рейтинг настроения. Бот реагирует на позитивные, нейтральные и критические сообщения, изменяя внутренний показатель настроения пользователя.

Проект демонстрирует работу Telegram Bot API, обработку текстовых сообщений, хранение состояния пользователей и построение простой системы оценки эмоционального состояния.

## Основные возможности  
- Отслеживание настроения пользователя на основе его сообщений  
- Изменение рейтинга настроения при каждом сообщении  
- Критические сообщения полностью сбрасывают настроение до –3  
- Хранение состояния каждого пользователя отдельно  
- Командное меню Telegram с подсказками команд  
- Приветственное сообщение при запуске команды /start

---

## Команды бота  

- /start — запуск бота и приветственное сообщение  
- /reset — сбросить рейтинг настроения  
- /help — показать список доступных команд  

Команды отображаются в виде меню подсказок Telegram, которое появляется в поле ввода.

## Архитектура  

### Основные классы

TelegramBot
- основной класс бота  
- принимает сообщения пользователей  
- обрабатывает команды  
- отправляет ответы  

UserMoodTracker
- хранит рейтинг настроения пользователей  
- изменяет рейтинг на основе сообщений  
- устанавливает рейтинг –3 при критических сообщениях  

BotConfig
- хранит токен и имя бота

## Установка и запуск

1. Установите JDK 21

2. Клонируйте репозиторий
git clone <repository-url>

3. Перейдите в папку проекта
cd telegram-mood-bot

4. Установите зависимости
mvn clean install

5. Добавьте Telegram Bot Token в BotConfig.

6. Запустите приложение
mvn exec:java

---

## Использование

1. Найдите бота в Telegram  
2. Отправьте команду /start  
3. Напишите сообщение  
4. Бот проанализирует текст и обновит ваш рейтинг настроения  
5. Используйте /score, чтобы посмотреть текущий результат

---

## Особенности реализации

- Рейтинг хранится в Map<Long, Integer>, где ключ — ID пользователя Telegram  
- При обработке сообщений используется простая логика анализа текста  
- Критические сообщения мгновенно устанавливают рейтинг –3  
- Команды Telegram добавлены через setMyCommands, поэтому отображаются в виде меню

---

## Ограничения и известные проблемы

- Анализ настроения реализован по ключевым словам и может быть неточным  
- Рейтинг хранится только в памяти и сбрасывается после перезапуска бота  
- Отсутствует база данных для долговременного хранения  
- Автоматические тесты пока не добавлены
